# منصة إتقان الإنجليزية | English Mastery Platform

منصة تعليمية تفاعلية شاملة للغة الإنجليزية تعتمد على **React + TypeScript + Tailwind CSS v4 + Vite**، مصممة بهوية بصرية مبهجة وتنظيم منهجي متدرّج يدعم المنهج المصري ومسار التأسيس الشامل، مع بنية جاهزة للتوسع نحو المنهج السعودي والفصول الدراسية القادمة.

---

## أبرز المميزات (Key Features)

- **قسم التأسيس الشامل (`Let’s Remember`)**: 10 محاور أساسية لقواعد اللغة الإنجليزية (القواعد بالإنجليزية + شرح التركيب بالعربية)، طرق التعلم الذكي، وخرائط المفاهيم التفاعلية.
- **منهج الصف الثالث الإعدادي — الفصل الدراسي الأول**: 6 وحدات دراسية متكاملة و18 درساً تفاعلياً.
- **الشرح المفصل والقواعد (`English Rules + شرح التركيب`)**:
  - عرض جميع القواعد والصيغ باللغة الإنجليزية متبوعةً بشرح تركيبها بالعربية.
  - تطبيقات عملية محلولة خطوة بخطوة (`Worked Practice`)، مفاتيح لغوية، جداول بادئات ولواحق، محادثات، وورش كتابة احترافية.
  - **مُفكّك الجمل الذكي**، **الشرح الصوتي التتابعي** (بريطاني UK / أمريكي US وبسرعتين)، و**وضع السبورة التفاعلية** بملء الشاشة.
  - دفتر ملاحظات ذكية محفوظ تلقائياً لكل درس + اختبار فهم فوري (`+15 XP`).
- **أوراق عمل تفاعلية وتصدير احترافي**:
  - 270 سؤالاً متدرجاً (10 أسئلة اختيار من متعدد + 5 أسئلة صواب وخطأ لكل درس).
  - تصدير أوراق العمل ومذكرات الشرح بصيغتي **Word (`.doc`)** و**PDF (طباعة منسقة)**.
- **أدوات التفوق والتعزيز**: المخطط التراكمي للقواعد، نظام التقييم التكيفي، المعجم التفاعلي وبطاقات الحفظ، ركن التحدي اللفظي، مجتمع نقاش أسفل كل درس، ولوحة متابعة الإنجاز.

## التشغيل المحلي (Local Development)

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. التحقق من بيانات المنهج (6 وحدات / 18 درساً / 270 سؤالاً)
node scripts/verify-curriculum.mjs

# 3. تشغيل خادم التطوير
npm run dev

# 4. بناء النسخة الإنتاجية
npm run build
```

## النشر على GitHub Pages

المشروع مجهّز بملف النشر التلقائي [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) وإعداد المسار النسبي `base: './'` في [`vite.config.ts`](vite.config.ts):

1. ارفع المشروع إلى مستودع جديد على GitHub على فرع `main`.
2. من إعدادات المستودع على GitHub انتقل إلى **Settings → Pages → Build and deployment → Source** واختر **GitHub Actions**.
3. سيتم البناء والنشر تلقائياً عند كل `push` على فرع `main`.
